This repo is the overview and index for the office Skills suite. Each office direction lives in its own repository; this page only lists directions, status, and entry points. Install and usage details stay in each child repo.

<a id="en-map"></a>
### Skill map

| Repo | Use case (how it helps you) | Tech path | Status |
|---|---|---|---|
| [**AI Video Skills · AI 视频 Skill**](https://github.com/huaxialucaicaizi/ai-video-skills) | Want explainer, talking-head, promo, and other office videos (10 types) but can't edit: AI helps you produce or rough-cut | Code-generated (HyperFrames) + traditional editing (AI rough cut, CapCut/Jianying polish) | In development (v1) |
